# odexis (plugin)

Five skills and three automatic steps that keep a project's thread, safety, forms and growth steady while the model does the work.

- `skills/setup`: `/odexis:setup` writes the project's first files after saying what it will add; `/odexis:setup remove` takes odexis's lines out.
- `skills/plan`: an interview and one approved plan for large or unclear work.
- `skills/grow`: where a new lasting rule, form or skill of the project belongs.
- `skills/prune`: `/odexis:prune` proposes what the project no longer needs.
- `skills/report`: prepares a report to odexis's makers about something that did not work, shows it and hands over a filled link; it sends nothing.
- `hooks/`: one line of facts at session start; one fact when the corrections noted in `odexis/status.md` changed in the conversation and one may have come twice; before a shell command, the project's own rules on files that are not to be read. They change no file of the project. `hooks.json` and `hooks/run.cmd` are how Antigravity starts them.

Installation and use are described in the README of the repository.
